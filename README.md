# Luca's Amazing Race — Wreckyard Edition

Godot 4 arcade demolition racing prototype. Built as an original racing game, not a copy of Wreckfest.

## Playing on Windows

Click **Code → Download ZIP**, extract it, launch **Godot 4**, import `project.godot`, then press **F5**.

## Features
- Dirt oval racing with nine cars (you + eight AI opponents)
- Three-lap race with position and lap tracking
- Demolition derby mode
- Arcade car handling and chase, overhead and hood cameras
- Collision damage, detachable bumpers, sparks and smoke
- Basic garage-style stock car models and scenery generated in code

## Controls

- **W / ↑** accelerate
- **S / ↓** brake or reverse
- **A/D or ←/→** steer
- **Space** handbrake
- **1** oval race
- **2** demolition derby
- **C** switch camera
- **R** restart mode

## Status

This is an experimental playable prototype, not a full soft-body vehicle simulator. Godot runtime testing on Windows is still needed. No external art assets are required.
